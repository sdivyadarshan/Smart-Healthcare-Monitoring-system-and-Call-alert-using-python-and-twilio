# Contribution and AI disclosure

## Project author contributions

The project author originated the project goal and selected the overall hardware/software approach. The author reports carrying out the physical assembly and wiring, installing the development tools and libraries, uploading and testing firmware, debugging the DS18B20 reading issue, testing the button behavior, setting the demonstration thresholds, creating the Twilio account, and validating SMS and voice-call integration.

## AI-assisted work

AI assistance was used during development for troubleshooting suggestions, code restructuring and review, Python/Twilio integration guidance, and preparation of repository documentation, architecture descriptions, and testing checklists.

## Attribution principle

This disclosure distinguishes the author's hands-on project work and design decisions from AI-assisted code and documentation support. It does not claim that every line of code was independently authored by the student. The author should review, understand, and validate all committed source code before submission or reuse.
